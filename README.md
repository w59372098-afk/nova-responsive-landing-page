# NOVA — Responsive Landing Page

A polished, responsive creative-studio landing page built with semantic HTML5, modern CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser. No build tools or package installation are required.

## Project files
- `index.html` — semantic page structure and content.
- `style.css` — visual design, CSS-built artwork, layout, and responsive breakpoints.
- `script.js` — accessible mobile navigation toggle, menu closing behavior, and dynamic footer year.

## Features
- Sticky header with desktop navigation and mobile menu toggle.
- Hero, selected work, services, about, contact, and footer sections.
- CSS Grid and Flexbox layouts that adapt for tablet and mobile widths.
- Accessible skip link, navigation labels, keyboard focus states, and reduced-motion support.
- No JavaScript frameworks or runtime dependencies.

## Design notes
The design uses a warm neutral background, bold editorial typography, lime accents, and abstract geometric artwork. Project artwork is made with CSS, so no image downloads are needed. Google Fonts are optional; system fallbacks remain available if fonts cannot load.
